claude doctor dice instalaciones duplicadas

Qué está pasando

Restos de otra vía de instalación

01Diagnóstico probable

Restos de otra vía de instalación. Cada vía tiene su procedimiento de desinstalación y no son intercambiables, así que instalar por una encima de otra deja dos binarios y el PATH decide cuál gana, que casi nunca es el que crees.

02Compruébalo

$ claude doctor

En la terminal. Mira la sección de problemas de instalación. En una máquina limpia dice No installation issues found.

$ which -a claude

En la terminal. Mira más de una ruta significa más de una instalación

03Solución

  1. Decide con cuál te quedas. La nativa es la recomendada.
  2. Desinstala la otra con el procedimiento de su vía: Homebrew se desinstala con Homebrew, WinGet con WinGet, npm con npm. Borrar el binario a mano deja configuración huérfana.
  3. Vuelve a lanzar claude doctor y comprueba que sale limpio antes de dar el caso por cerrado.
Pasa si

which -a claude devuelve una sola ruta y claude doctor termina con No installation issues found.
